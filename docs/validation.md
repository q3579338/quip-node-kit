# v0.1.0 验证范围

核对日期：2026-10-22。以下是本版本实际完成的检查，不代表新服务器完整挖矿或积分收益已经得到保证。

## 已完成

- Linux Python 3.12.3：16 项离线单元测试全部通过。覆盖参数、独立身份目录、重复安装保留身份、陌生目录与容器拒绝覆盖、已启动身份缺失时拒绝重新生成、钱包字段更新，以及积分快照的账户与时间窗口校验。
- `bash -n install.sh` 通过。
- 在安装了真实 Docker Compose 的 Linux 环境中，分别解析 1、4、5 个实例的生成配置；5 实例方案明确允许超线程。确认每实例 CPU 额度为 1、内存上限为 1GiB、状态端口只绑定 `127.0.0.1`，CPU 分配按计划生成。
- 配置检查没有启动或重启容器，没有生成真实矿工身份，没有调用 EVM 钱包，也没有改动现有矿工。
- 预演模式不创建运行状态目录。测试中的钱包和 IP 均是明确的离线占位值。
- 三个默认官方 RPC 的只读创世区块查询均与本版本固定的 Aglais spec119 创世区块一致。网络可用性会随时间变化，正式安装仍会重新校验。

## 尚未完成或不作保证

- 本版本没有在全新服务器上完整执行一次 Docker APT 安装、首次登记、计算到获胜的端到端流程。使用的是官方固定摘要镜像，仍需要部署者核对实际登记和运行状态。
- 未验证 ARM 架构；部署命令当前只接受 Linux x86_64。
- 未证明同一钱包多实例、不同钱包或同一 IP 的计分规则与收益倍数。
- 未证明邀请即时到账、固定每日 QP、空投资格或任何现金收益。
- 测试不包括云厂商公网入口配置；填写公开描述字段不会自动开放端口或建立反向代理。
